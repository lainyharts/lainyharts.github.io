# LainyHarts Creature Company

Finger-knit pufflings. Live at https://lainyharts.github.io/

Plain HTML + CSS, no build step. Edit `index.html` and `style.css`, drop photos in `images/`.

When you change `style.css` or `form.js`, bump the `?v=` number on its link in `index.html`. Otherwise visitors can get the old cached file for up to 10 minutes.
